# Teamora frontend

Next.js client for the weekly reporting workflow.

## Run locally

1. Start the Spring Boot API on `http://localhost:8080`.
2. Install packages with `npm install`.
3. Start the application with `npm run dev`.
4. Open `http://localhost:3000`.

The frontend includes login/registration, report editing and history, manager review, project management, user management, and the filtered team-insights dashboard.
